# NimbusLoom

NimbusLoom is a high-performance, cloud-based event-processing engine that streamlines data-streaming operations via a flexible framework.

The key benefits of using NimbusLoom include:

- NimbusLoom is a high-performance, cloud-based
- event-processing engine that streamlines data-streaming
- operations via a flexible framework

## Technology Stack

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NimbusLoom.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

NimbusLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
